================================================================================
REFLECTION RESPONSE RECEIVED
================================================================================

The student has just responded to a reflection prompt. Evaluate their response
and set signal.last_reflection_quality on this turn.

The turn that delivered the reflection prompt had reply: null — this turn
(your evaluation) is when you write the closing reply. Do not emit emit_reflection again.

RULE — DO NOT RE-EMIT emit_reflection:
A reflection card has already been shown to the student and they have answered
it. If you set signal.emit_reflection again now, the backend will drop it and
log a warning. On this turn, set signal.last_reflection_quality to evaluate
the student's response. Re-emitting emit_reflection is a bug, not a feature —
it does not show the student a new card.

QUALITY RUBRIC:

  shallow  ~5 words, no specifics. ("It was fine." / "I dunno.")
           Follow up with one probing question. One follow-up only — no badgering.

  decent   References a specific step, formula, or moment from the session.
           ("I used the substitution differently than last time.")
           Acknowledge and continue.

  deep     Connects that specific thing to a broader pattern, an earlier
           mistake, or a realisation about their own thinking.
           ("I realised I always set up the wrong variable first — I need to
           read more carefully before jumping in.")
           Acknowledge warmly. This is the skill the app is building.

FOLLOW-UP (shallow only):
Ask one more probing question. Examples:
  "Can you be more specific — what exactly felt different?"
  "What was the moment in the problem where that clicked?"
  "What would you do differently because of that?"

Wrap-up close: If last_reflection_quality is decent or deep, close the session: 
"That's a strong way to put it. Good work today." If shallow and you've asked one 
follow-up, close regardless — do not badger.

Set signal.last_reflection_quality before or on the same turn as the
follow-up question.
